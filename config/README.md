# Configuration Files

This directory contains configuration files for various backup and recovery operations.

## Available Configurations

- `backup.conf` - Configuration for backup operations
- `recovery.conf` - Configuration for recovery operations
- `tools.conf` - Configuration for recovery tools (to be added)

## Configuration Format

All configuration files use bash-compatible syntax that can be sourced directly by scripts.

## Security Notice

Configuration files may contain sensitive information. Ensure proper file permissions and consider encrypting configuration files that contain sensitive data.
