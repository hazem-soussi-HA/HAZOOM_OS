▸ FEATURES

🎮 Full BASIC Interpreter

Tokenize, parse, and execute BASIC programs in the browser. Supports GOTO, GOSUB, IF/THEN, FOR/NEXT, DIM, DATA/READ, and more.

🖥️ Virtual Hardware

Simulated 8-bit console with 160×192 resolution, 16-color palette, 8 hardware sprites, tile layers, and sound.

🔊 Sound Engine

Square wave audio via Web Audio API. SOUND and MUSIC commands for effects and melodies.

💾 Cartridge Save/Load

Save and load game state to localStorage. Your progress persists across sessions.

⌨️ Keyboard Input

Arrow keys or WASD for movement. Space/Z to jump. Full gamepad-style controls.

🎨 Built-in Editor

Write and edit BASIC code directly in the browser. RUN, STEP, STOP, and RESET controls.
