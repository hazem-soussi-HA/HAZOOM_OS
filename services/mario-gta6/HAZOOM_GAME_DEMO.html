⚙ ENGINE FEATURES

Full-stack game engine — from memory management to rendering pipeline

⚡

Rust → WASM Physics

Zero-cost physics hot path compiled from Rust to WebAssembly. Branch-free tile lookup. Linear memory layout. Near-native speed in browser.

🎮

ECS Architecture

Entity-Component-System design. Decoupled systems: physics, rendering, AI, audio. Cache-friendly data layout. O(1) entity lookup.

🤖

AI Behavior Trees

State-machine + behavior tree hybrids. Enemy awareness, patrol patterns, player prediction. Configurable difficulty via JSON.

💡

Dynamic Lighting

Phong + Toon shading hybrid. Dynamic point lights for explosions, power-ups, vehicle headlights. Shadow maps for open-world depth.

🔊

Spatial Audio

Web Audio API with HRTF panning. Engine RPM tied to physics. Distance attenuation. Dynamic music system for gameplay states.

🌍

Open-World Streaming

Chunk-based world loading. LOD system for distant objects. Road generator with procedural placement. Save/load with compression.
