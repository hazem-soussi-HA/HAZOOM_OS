02 / 08

◈ THE ENGINE

Rust→WASM

Physics hot path compiled to WebAssembly. Branch-free tile lookup. Near-native speed in any browser.

Three.js

WebGL rendering with dynamic lighting, toon shading, particle FX, and spatial audio.

ECS

Entity-Component-System architecture. Cache-friendly. O(1) lookup. Decoupled systems.

AI Trees

Behavior trees + state machines. Enemy awareness, patrol, chase, player prediction.

Open World

Chunk streaming, LOD, procedural roads, save/load with compression.

Zero Deps

No game engine. No framework. Pure Rust + JavaScript + GLSL. Full control.
