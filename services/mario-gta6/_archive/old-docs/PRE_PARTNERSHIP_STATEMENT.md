# Pre-Partnership Statement of Intent

**Author:** Hazem Soussi (HA) — <https://github.com/hazem-soussi-HA>
**Project:** SUPER MARIO GTA6
**Date:** June 2026
**Status:** Living document — last revised 2026-06-04

---

## 1. Purpose of this Document

This statement exists to put on record, in clear and good-faith
language, the relationship between the **SUPER MARIO GTA6** project
and the two companies whose work inspired it: **Nintendo Co., Ltd.**
(creators of the *Super Mario Bros.*® series) and **Take-Two
Interactive Software, Inc. / Rockstar Games, Inc.** (creators of the
*Grand Theft Auto*® series).

The author's intent is to:

  1. Acknowledge, with respect, the IP that inspired this work.
  2. Make absolutely clear that **no partnership, license, or
     endorsement currently exists.**
  3. Express a sincere, professional interest in a future dialogue
     with either IP holder, on their terms, if such dialogue is ever
     welcome.
  4. Document the steps already taken to keep the project in
     compliance with Nintendo's published *Game Content Guidelines
     for Fan Works* and with general fair-use principles for
     non-commercial homage.

This is a portfolio piece and a love letter to the platformer genre.
It is **not** a commercial product, **not** a competing release, and
**not** a substitute for any official Nintendo® or Rockstar® title.

---

## 2. The Author's Position

The author is an independent game developer who has built this
project entirely in his own time, using original code, procedurally
drawn sprite art, and procedurally generated sound. No copyrighted
assets from Nintendo or Rockstar have been copied into this
repository. Every visual element is drawn at runtime from
mathematical primitives; every sound effect is synthesized via the
Web Audio API or pygame's mixer; every music track is generated by
a small Markov-chain melody engine that ships in the source.

The author has deep personal affection for both the *Super Mario*
series and the *Grand Theft Auto* series, and built this project
as an exercise in:

  • Studying and re-implementing classical 2D platformer mechanics
    (coyote time, jump-buffering, variable jump height, momentum
    preservation) from first principles
  • Studying the design philosophy of open-world driving games and
    building a tiny homage with the same "press a key, get in a car"
    feel
  • Demonstrating the full lifecycle of a real game project —
    engine, level, art, audio, HUD, save system, website, build
    pipeline, and legal hygiene

The combination of those two inspirations under one project name is
meant as a tribute, not as a claim of ownership over either lineage.

---

## 3. What This Project Is NOT

To remove any ambiguity, this project is **not**:

  • An official Nintendo® or Rockstar® product of any kind
  • A licensed, sponsored, or endorsed work
  • A commercial product (it is offered free of charge, with no
    ads, no in-app purchases, no premium tier, and no monetization
    of any kind)
  • A replacement for, or a competitor to, any official title
  • A reverse-engineering effort — no Nintendo or Rockstar binaries
    have been disassembled, decompiled, or analyzed to produce any
    code in this repository
  • A work that uses any sampled sprite, sound, or music from any
    Nintendo or Rockstar title

If any of the above statements is found to be inaccurate, the
project will be corrected or removed.

## 4. What the Author Hopes For

The author hopes — without expectation and without deadline — that
this project may, at some future point, be a useful piece of
portfolio or conversation-starter for a legitimate dialogue with
either IP holder. The "fan project → hired contributor → official
release" pathway is well-trodden in the games industry:

  • **Christian Whitehead** built *Sonic CD* (2011) as a fan remake
    using his own Retro Engine, and was subsequently hired by SEGA
    to develop *Sonic Mania* (2017)
  • **Nintendo Co., Ltd.** hired the developer of *AM2R* (the
    fan-made *Metroid II* remake) in 2016, a year after the fan
    project was shut down
  • **Toby Fox** cited *EarthBound* as a direct inspiration for
    *Undertale*, and later collaborated with Nintendo on
    *Super Smash Bros. Ultimate*
  • **Capcom** has a long history of hiring from its *Street
    Fighter* and *Mega Man* fan-modding communities

The author would welcome the opportunity to follow any of these
pathways. The author is equally prepared for the more likely
outcome: that this project remains a personal portfolio piece, that
it is eventually asked to be renamed or taken down, and that the
author simply continues to build original work.

Either outcome is acceptable. The author's respect for the IP
holders is not contingent on the outcome.

## 5. Compliance Posture

This project is structured to remain in compliance with Nintendo's
published fan-work guidelines and with general trademark respect:

  1. **No commercial use.** The project is offered free of charge.
     See `LICENSE` for the MIT grant on the original code.
  2. **No copied assets.** All sprites, sounds, and music are
     procedurally generated. See `LICENSE § STATEMENT OF ORIGINALITY`
     for the line-by-line distinction.
  3. **Clear non-affiliation notice.** The required attribution
     text appears in `TRADEMARKS.md` and is rendered in the
     in-game credits and on the project website footer.
  4. **Takedown cooperation.** If either IP holder requests
     modification, renaming, or removal, the author will comply
     promptly. See `NOTICE_TO_IP_HOLDERS.md` for the contact
     pathway.
  5. **Original code, MIT-licensed.** All authored code is
     available under a permissive license so that the work can
     outlive any forced renaming — the engine, the website, the
     reward system, the build pipeline, and the documentation can
     all be reused by anyone, including by the original IP holders
     should they ever wish to.
