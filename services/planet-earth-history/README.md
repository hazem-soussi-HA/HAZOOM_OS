# planet-earth-history

Planet Earth History service for HAZOOM_OS. Tracks and visualizes historical earth data, climate patterns, and geological timelines.

## Structure
- `app.js` / `engine.js` - Core application logic
- `data.js` - Data management
- `serve.py` - Python server
- `static/` - Static assets
- `config.yaml` - Configuration
- `scripts/` - Utility scripts
- `tests/` - Test suite

## Dependencies
- Python
- Node.js

## Server
Run `python3 serve.py` to start the history service.
