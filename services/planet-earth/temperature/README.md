# Temperature Meteorology — Worldwide Countries

A modern, fully-offline platform that shows per-country temperature across
**all ~197 countries** on a real-scale 3D globe, with a searchable worldwide
ranking table and a transparent methodology panel.

It is built in the same air-gapped spirit as the rest of this repo: **zero
runtime network calls, no CDN**, Three.js is vendored locally (r160).

## Run it

From the repo root (the existing server already knows the route):

```bash
python3 server.py
```

Then open: <http://127.0.0.1:8080/temperature>

The server is bound to `127.0.0.1` only — never reachable from the network.

## Features

- **3D globe** (real-scale sphere, ocean + atmosphere limb glow, procedural
  starfield, UnrealBloom post-processing) with one temperature node per country.
- **Temperature color ramp** — diverging scale from cold blue → purple →
  green → amber → hot red/white (~ −25 °C to +30 °C), matching the legend.
- **Hover** any node for a tooltip; **click** it (or a table row, or a search
  result) for a detail card and automatic camera focus.
- **Search** with keyboard navigation (↑/↓/Enter) across all countries.
- **World ranking table** — sortable by temperature, name, or region; filter
  by region; click to fly to the country.
- **Live local clock** and an FPS/HUD overlay.
- **Methodology & honesty modal** explaining exactly how the numbers are made.

## Honesty: these are MODELED values, not live readings

You opted to keep this app offline, so it does **not** pull live station or
weather-model data. Instead each country's number is a transparent,
reproducible reconstruction of its **annual-mean temperature**:

```
T(°C) = 27.0 − 0.0145·|lat|^1.8 − 0.0065·elevation_m + continentality_tweak
```

- `27.0` — warm-equator baseline.
- `−0.0145·|lat|^1.8` — latitude / isolation gradient (diminishing toward poles).
- `−0.0065·elevation_m` — standard environmental lapse rate (≈ −6.5 °C / 1000 m).
- `continentality_tweak` — small manual nudge for continental-interior cold or
  maritime warmth.

Inputs (country coordinates + mean elevation) are public reference values.
The dataset is generated by `scripts/build_temps.py` → `data/temperatures.json`.
Re-run the script to audit or extend the list.

### Want real-time data?

`src/app.js` ships a `fetchLiveTemperature()` hook that maps onto the public
Open-Meteo API. It is **disabled by default** (`LIVE_API_ENABLED = false`).
Flip that flag to `true` and provide network egress to wire real observations;
when live data is used, the UI will mark the value as **LIVE** instead of
**MODELED**.
