📐 Methodology & honesty

This platform is built fully offline (no network, no runtime CDN) in the same air-gapped spirit as the Planet Earth globe it lives beside.

These are modeled climatologies, not live observations. The number shown for each country is a transparent reconstruction of its annual-mean temperature, not a real-time thermometer reading.

Why modeled?

You opted to keep this app offline (network egress denied). Live station or model data (e.g. Open-Meteo, NOAA) would require a network call. Rather than fake "live" numbers, we show an honest, reproducible estimate and label it clearly.

The formula

T(°C) = 27.0 − 0.0145·|lat|^1.8 − 0.0065·elevation_m + continentality_tweak

Each term is documented and checkable:

  • 27.0 — warm-equator baseline (°C).
  • −0.0145·|lat|^1.8 — diminishing temperature drop as you move from the equator toward the poles (isolation/latitude effect).
  • −0.0065·elevation_m — standard environmental lapse rate (≈ −6.5 °C per 1000 m of altitude).
  • continentality_tweak — a climate correction, NOT a blanket cold penalty. Hot arid/desert lands (Sahara, Arabia, Mesopotamia, Thar, interior Australia) get a +1.5 °C warmth nudge; only genuinely cold high-latitude interiors (Greenland, Russia, Canada −3 °C; Mongolia, Kazakhstan −2 °C) keep a negative nudge; high mountains (≥1500 m) are pulled cold. Everything else trusts the latitude/elevation formula.

Inputs

Country reference coordinates and mean elevations are public reference values (World Bank / CIA World Factbook approximations). The dataset is generated by scripts/build_temps.py and written to data/temperatures.json — re-run it to audit or extend the list.

Real-time data (live mode)

src/app.js ships a fetchLiveTemperature() hook onto the public Open-Meteo API (LIVE_API_ENABLED = true). When network egress is available it shows the actual current temperature for a selected country and marks the detail card LIVE. When offline, the call fails fast (4 s timeout) and the value cleanly falls back to the MODELED climatology above — clearly labeled. No key, no account.

Reproducibility

Every value is deterministic from the inputs above. Nothing is hidden and nothing is invented — matching the project's "Verify the truth" standard.
