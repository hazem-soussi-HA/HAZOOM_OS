# Brand / Logo assets for The New Age of Birds

All marks are generated **locally as SVG** (no third-party image services, no cloud),
consistent with the project's strict offline / confidential security posture.

## Files
- `logo-icon.svg`      — square emblem (512×512). Use as app icon / favicon / GitHub avatar.
- `logo-horizontal.svg`— emblem + wordmark lockup (760×200). Use for README headers, docs, social.

## Design language
- Midnight-blue field `#0b1020` with electric-cyan `#2a6cff` wireframe globe (the "3D / AGI" motif).
- Low-poly crowned-crane-in-flight in feather-gold `#f2c14e`, emerald `#2e7d32`, cyan `#3f86ff`.
- A red crown tuft `#ff2e2e` nods to the Grey Crowned Crane (national bird of Uganda).
- Africa landmass silhouette in emerald anchors the subject to the continent.

## Usage
- These are vector; scale freely. For a raster PNG/favicon, rasterize locally (e.g. `rsvg-convert`
  or any offline converter) — do NOT upload source art to any web service.
- Keep the emblem inside the rounded shield; preserve clear space.

## Security note
No logo asset in this folder was produced or transmitted via external/cloud image APIs.
Generation was performed entirely on-device.
