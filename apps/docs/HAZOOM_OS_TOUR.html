🚀 Welcome to HAZOOM OS

HAZOOM OS v4.0 - Pascal Engine Edition is a browser-based operating system that implements real kernel concepts in JavaScript. It features a Pascal Engine ported from original Pascal source code, process scheduling, memory management, virtual filesystem, and ring-based security.

Mission Statement

"Operating Systems Thinking — Real kernel concepts brought to life in the browser through Pascal Engine neural processing"

Built with Node.js, Express, and Vanilla JavaScript, HAZOOM OS implements actual OS concepts like process management, memory paging, filesystem inodes, and device drivers — all running in your browser.

🚀 Getting Started

Launch HAZOOM OS with Node.js and explore its powerful features. The system is designed to be intuitive and accessible.

🖥️
Start Server
Command: node server.js
Port: 3000 (default)
Features: Express + WebSocket
🌐
Open Browser
Navigate to http://localhost:3000 to access the HAZOOM OS desktop interface.
🎯
Launch Apps
Click desktop icons or use the start menu to launch applications.
⚙️
Configure
Access Settings to customize your experience. Configure themes, preferences, and more.
