About HAZOOM OS

HAZOOM OS v4.0 is a browser-based operating system simulation that implements real kernel concepts in JavaScript. It features a Pascal Engine with neural processing, process scheduling, memory management, virtual filesystem, device drivers, and ring-based security — all running in your browser.

The kernel modules are ported from Pascal source code to JavaScript, bringing operating systems theory to life. The Pascal Engine powers neural consciousness, dream simulation, emotional empathy processing, and pulse-based networking — making HAZOOM OS one of the most ambitious web-based OS projects ever built.

The HAZOOM Philosophy

"Operating Systems Thinking"

Academics enjoy the luxury of being able to study what is interesting about operating systems, especially clever algorithms, data structures and occasionally, areas that lend themselves nicely to mathematical analysis. Industry professionals must build real systems that work and meet the demanding cost, performance and reliability requirements of customers.

Both kinds of thinking are rich with interesting issues. There are considerable overlaps as well as significant differences in what academics and industry professionals think about. Hazoom aims to present a balanced treatment of both the academic and industry sides of operating systems theory and practice.

Features
Pascal Engine:
AetherEngine (neural processing), NeuralCore (AI inference), DeepConsciousness (dream simulation), and SynapseOS (pulse-based networking with PheromoneNet and EmpathyEngine)
Process Management:
Real process scheduling with round-robin, process states (ready/running/blocked), PID tracking, and system call handling
Memory Management:
Virtual memory with paging, TLB simulation, page fault handling, and process memory isolation
Virtual Filesystem:
Node.js-backed filesystem with inodes, directories, permissions, and persistent storage
Security System:
Ring 0-3 privilege levels, capability-based access control, and syscall validation
40+ Applications:
Games (Chess, Tetris, Flappy Bird), AI assistants, system monitors, development tools, and neural visualizers
Real-time Updates:
WebSocket-powered kernel state monitoring with live process, memory, and filesystem updates
