🔍 Hazoom Search API Mock

This is a mock API endpoint for Hazoom Search Engine. In a production environment, this would be a real backend service that handles web searches and returns results.

Note: This is a frontend mock for demonstration purposes. A real implementation would require a backend service to handle CORS and web scraping.

Available Endpoints:

POST /api/web-search

Request Format:

{
  "query": "search term"
}

Response Format:

{
  "success": true,
  "query": "search term",
  "results": [
    {
      "title": "Page Title",
      "url": "https://example.com",
      "snippet": "Brief description of the page content...",
      "type": "search_result"
    }
  ],
  "took": 0.123,
  "total_results": 1000000
}

This mock API simulates the functionality needed for the Hazoom Search Engine to perform web searches through a backend proxy to avoid CORS restrictions.
