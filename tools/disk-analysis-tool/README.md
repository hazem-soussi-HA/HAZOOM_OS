# Disk Analysis Tool

A simple tool for analyzing disk structure and health.

## Features
- Disk usage analysis
- File system check
- Bad sector detection
- Performance metrics

## Usage
```
./analyze.sh [options] [disk_path]
```

## Options
- `-v` : Verbose output
- `-c` : Check file system
- `-f` : Full analysis (takes longer)

## Requirements
- Administrative privileges
- Sufficient disk space for temporary files
