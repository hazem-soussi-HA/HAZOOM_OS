MCP Supervisor
==============

A supervisor application to manage all MCP agents on your PC.

Quick Start
-----------
1. Start the supervisor: .\start-supervisor.ps1
2. Available Commands:
   - list_agents - Show all agents and status
   - start_agent <id> - Start specific agent
   - stop_agent <id> - Stop specific agent
   - restart_agent <id> - Restart specific agent
   - start_all_agents - Start all enabled agents
   - stop_all_agents - Stop all agents
   - get_system_stats - Get system statistics

Configuration
-------------
Edit agents_config.json to add/remove agents.
